# Prefill support

## Getting help

- Read the README first. It covers using presets, permissions, settings and known limits.
- For a question, a bug or a request, write to sidharth.thamban@gmail.com or open an issue at https://github.com/s1dharthpv/prefill/issues.

## What to include

- Your Frappe version (the output of `bench version`)
- The DocType you were using and what you did, step by step
- What you expected and what happened instead, with the error message if there was one
- A screenshot, if it helps

Please do not send real customer or financial data. Describe the values instead, or use made-up ones.

## Response

Support is provided on a best-effort basis.

## Security issues

Report a suspected security problem privately to sidharth.thamban@gmail.com instead of opening a public issue. Please give the details above and allow time for a fix before sharing it more widely.
